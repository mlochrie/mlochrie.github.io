Activity 2: Transforming Data Using .map()

Users often enter product names using inconsistent capitalisation.

Example:

xxxxxxxxxx
chocolate cake
BLUEBERRY muffin
 lemon tart

Use .map() to convert each product name to Title Case.

Example output:

xxxxxxxxxx
Chocolate Cake
Blueberry Muffin
Lemon Tart

Example Algorithm

xxxxxxxxxx
String toTitleCase(String text) {
    return text
        .trim()
        .split(' ')
        .where((word) => word.isNotEmpty)
        .map(
            (word) => '${word[0].toUpperCase()}${word.substring(1).toLowerCase()}',
        )
    .join(' ');
}

Note

This code takes a String input and and performs a transformation on the String. The result is the text has a capital letter at the start of each word

Create a new dart file (to_title_case.dart) within the lib directory and paste the above algorithm inside the file. Save and exit the file.

Import the file in the main.dart 

xxxxxxxxxx
import 'to_title_case.dart';

Update the setState() method to call toTitleCase and pass it newItem

xxxxxxxxxx
bakeryItems.add(toTitleCase(newItem));
