Introduction

Creating applications that function correctly is only part of mobile application development. Users also expect applications to be visually appealing, accessible and responsive across a range of devices.

In this lab you will build a Student Dashboard application while exploring Flutter's styling capabilities. You will progressively improve the application's appearance by introducing responsive layouts, colour schemes, typography, themes and custom fonts.

By the end of the session, you will have transformed a basic Flutter application into a polished interface that follows Flutter's Material Design principles.

Activity 3 – Using MediaQuery

Applications run on many different screen sizes.

Flutter provides MediaQuery to access information about the device.

3.1 Obtain Screen Information

Inside your widget build method, create the following variables:

x
final screenWidth = MediaQuery.of(context).size.width;
final screenHeight = MediaQuery.of(context).size.height;

Print the values to the debug console. If you are running a Chrome application adjust the side of the window and see the values printed to the debug console.

Alternatively, run the application on:

  • A phone emulator.

  • A tablet emulator (if available).

3.2 Responsive Container

Create a container whose width is based upon screen size.

Notice how all the Widgets are centred? Before we added the the Center Widget all the Widgets were on the left, this was because the Widgets took up on the space they required and were actually centered to the left. A Column Widget will default center everything. Unless we add, inside the Column Widget

xxxxxxxxxx
crossAxisAlignment: CrossAxisAlignment.start,

Save the code and let Hot Reload, reload the view. Notice the student information is now aligned to the left and the SizedBox remains in the center.

One way to achieve this would be to create the template for a card.

xxxxxxxxxx
class DashboardCard extends StatelessWidget {
    final String title;
    final IconData icon;
    
    const DashboardCard({super.key, required this.title, required this.icon});
    @override
    Widget build(BuildContext context) {
    return Card(
      elevation: 4,
      child: SizedBox(
        height: 140,
        child: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Icon(icon),
              const SizedBox(height: 10),
              Text(title, style: Theme.of(context).textTheme.bodyLarge),
            ],
          ),
        ),
      ),
    );
    }
}

This creates a card with Icon and Text Widgets.

Now you can use this class to instantiate the three cards for (Assignments, Attendance, Grades).

In Flutter you can defer the building of a Widget until the view is loaded.

Note

This was not covered in the lecture, however, use the code below to support your understanding

Add the following below the Center Widget within the view.

xxxxxxxxxx
LayoutBuilder(
builder: (context, constraints) {
        bool isWide = constraints.maxWidth > 600;


        if (isWide) {
          return Row(
           children: const [
              Expanded(
                child: DashboardCard(
                  title: 'Assignments',
                  icon: Icons.assignment,
                ),
              ),
              SizedBox(width: 10),
            ],
          );
        }


        return const Column(
            children: [
                DashboardCard(title: 'Assignments', icon: Icons.assignment),
                SizedBox(height: 10),
            ],
        );
    },
),

This will detect the screen orientation and decide how to layout the Widget

Add further cards for Attendance and Grades.

Tip
